# Support

Use the right channel so that maintainers and contributors can respond efficiently.

- Ask setup and usage questions in [GitHub Discussions](https://github.com/martinthommesen/oxc-plugin-servicenow/discussions).
- Report reproducible defects with the bug report form.
- Propose new rules with the rule proposal form.
- Report vulnerabilities through [private vulnerability reporting](https://github.com/martinthommesen/oxc-plugin-servicenow/security/advisories/new).

Include the package version, Node version, host tool, configuration, and a minimal example.
Remove credentials, customer data, instance URLs, and proprietary ServiceNow code.

This project is maintained on a best-effort basis.
A question or proposal does not guarantee a response date or implementation.
