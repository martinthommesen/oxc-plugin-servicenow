# ES2021

Australia ES2021 lint loads the plugin with `javascriptMode` set to `es2021`, `release` set to `australia`, and `surfaces` set to `server`. A valid server script stays silent. `for await` reports `servicenow/no-async-iterators`. `DataView.prototype.getBigInt64` reports `servicenow/no-typed-arrays`. Private instance members report `servicenow/no-unsupported-syntax`.

## Sub-features

- `es2021-valid` lints `examples/es2021/valid` with no plugin diagnostics.
- `es2021-async-iter` reports `servicenow/no-async-iterators` on `async-iter.server.js`.
- `es2021-australia` reports `servicenow/no-typed-arrays` and `servicenow/no-unsupported-syntax` on `australia-engine.server.js`.
- `es2021-oxfmt` checks the valid server scripts with `oxfmt.recommended.json`.

## How to get to it (user POV)

- Copy `examples/es2021`, install `oxc-plugin-servicenow`, and run `npx oxlint -c .oxlintrc.json valid`.
- Run `npx oxlint -c .oxlintrc.json invalid` and expect the Australia engine bans.
- Run `npx oxfmt -c oxfmt.config.ts --check valid` after the package is installed.

## Driving it with verify-examples

Preconditions:

- `npm run verify:examples -- prepare --run-id <id>` exited 0.
- `examples/es2021` is unmodified.

- **Valid tree.** Run `npm run verify:examples -- --project es2021 --tree valid --run-id <id>`. Exit 0. `pluginRules` is `[]`.
- **Invalid tree.** Run `npm run verify:examples -- --project es2021 --tree invalid --run-id <id>`. Exit 0. The attempt matches the three expectations in `scripts/verify-projects.json`.
- **Format check.** Run `npm run verify:examples -- --project es2021 --tree oxfmt --run-id <id>`. Exit 0. `summary.json` has `"ok": true`.
- **Proof.** Open `run-summary.json` in the run directory. Use the attempt whose `project` is `es2021` and `tree` is `invalid`. Read that relative `dir` for `summary.json` and `stdout.json`. Run `git status -- examples/es2021` and require a clean tree.

## Gotchas

- Promise and async/await are allowed in this mode. Do not expect `no-promise` here.
- Private instance members and DataView BigInt getters stay banned on Australia.
- `release` must stay `australia`. A missing release changes which typed-array methods fire.
