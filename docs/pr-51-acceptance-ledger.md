## Layer rollback boundaries

1. Layer 1 can be reverted without retaining rules that depend on its context/settings contracts.
2. Layer 2 can be reverted together with dependent stateful consumers; later layers must not bypass it.
3. Layer 3 reverts classic/stateful consumers without reverting shared foundations.
4. Layer 4 reverts Fluent manifests and binding-aware rules without changing classic analysis.
5. Layer 5 reverts generated docs/evidence/profile/formatter changes with descriptors kept synchronized.
6. Layer 6 reverts packed compatibility/benchmark gates without changing release permissions.
7. Layer 7 is privileged and independently revertible; no implementation-layer changes belong in its commits.
